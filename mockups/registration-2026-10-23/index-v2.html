        How this page is made

        Nobody writes it. It's built from two things: what the registration team shared with this team (here: names, with the answers set to share), and each question's own setting in the program editor.

        • A question set to share as totals shows counts only, never names, even to a team shared at Names.
        • A question set to share with names shows counts with the people under each answer, or, for a written answer, each person's words.
        • Questions set for the registration team or teachers don't appear here at all.
