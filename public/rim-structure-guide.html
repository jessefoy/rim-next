RIM Connect — Programs Grouped List Structure

Each box = one Webflow element. Add the highlighted attribute in Element Settings → Custom Attributes.

List container / trigger
State element (auto shown/hidden)
Template (cloned per item)
Field binding
Conditional show/hide

Programs List Container div
data-rim-group-list="programs"
Outer wrapper. Fetches the API and drives everything inside. One per page.
Webflow name: Content Container
Loading State div
data-rim-state="loading"
Shown automatically while the API fetch is in progress. Hide in designer with display:none.
Empty State div
data-rim-state="empty"
Shown if the API returns zero programs. Hide in designer with display:none.
Error State div
data-rim-state="error"
Shown if the API call fails. Hide in designer with display:none.
↓ cloned once per category ↓
Category Block div
data-rim-group-item
Template for each category group. Cloned once per category that has programs. Hide in designer with display:none.
Webflow name: Program_Category_Container
Category Name h2
data-rim-group-field="name"
Receives the category name text (e.g. "Meditation", "Courses"). This is a category-level field, not a program field.
Webflow name: Program Category Header
↓ cloned once per program in this category ↓
Programs List Wrapper div / grid
data-rim-items
The container that holds all program rows for this category. rim-connect appends cloned program rows here.
Webflow name: programListBlock 3
Program Row div
data-rim-item
Template for each individual program. Cloned and populated per program. Hide in designer with display:none.
Webflow name: Dashboard List Name and Date Container
Name + Schedule Block div
Layout wrapper — no attribute needed. Contains the program name and schedule text.
Webflow name: Name Day and Time Block
Program Name h2 or h3
data-rim-field="name"
The program title. e.g. "Monday Sitting Group"
Webflow name: event-name 3
Schedule Label div / text block
data-rim-field="scheduleLabel"
Day/time pattern. e.g. "Mondays · 9:30–10:30 AM CT"
Webflow name: Text Block 97
Special Announcement Wrapper div
data-rim-show="specialAnnouncement"
Entire block hidden unless the program has a special announcement. Hide in designer with display:none.
Webflow name: Special Program Announcment
Announcement Text p / text block
data-rim-field="specialAnnouncement"
The announcement text itself. e.g. "Registration now open"
Webflow name: Special Announcment 2
Learn More Button a / link block
data-rim-href="/rim-next/program-detail?slug=[slug]"
Link to the program detail page. [slug] is replaced automatically with the program's slug.
Webflow name: Program List Button 2

Script tag to add in Page Settings → Before </body>:  <script src="https://rim-next.vercel.app/rim-connect.js" defer></script>
