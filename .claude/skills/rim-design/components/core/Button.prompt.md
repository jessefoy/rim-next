Pill-shaped action button — use for every clickable action on a RIM surface; never square corners.

```jsx
<Button variant="primary" size="md" href="/community-programs">Register</Button>
```

- `primary` filled `--rim-blue`, hovers to `--rim-mid`. The default.
- `secondary` white fill, blue 1px rule, blue label.
- `ghost` bare blue label — for cancel / tertiary.
- `donate` the only warm red (`#c23b3b`) in the system; reserved for the Donate CTA.
- Sizes: `sm` 36px, `md` 44px (the tap minimum), `lg` 50px for hero CTAs.
