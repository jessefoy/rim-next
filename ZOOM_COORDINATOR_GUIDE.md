# How Zoom Works at RIM: A Guide for Coordinators

This is for the people who set up programs and look after the teams that run them. Hosts have their own short guide ("Hosting a Session on Zoom"). This one explains what happens behind that, so you can set a program up once and trust it.

The idea underneath all of it is simple. RIM runs the schedule, and Zoom is the room. You never make a Zoom meeting or copy a Zoom link. You set the program up in RIM, and RIM opens the right room at the right time, for the right people.

## What you set in Program Manager

Everything Zoom needs comes from the program itself.

**Format.** A program that is *virtual* or *hybrid* meets on Zoom. An *in-person* program has no Zoom room at all.

**Schedule.** The start time, the end time, and how it repeats. The end time matters more than it looks. RIM holds a Zoom room for the whole session, so an accurate end time is what keeps two sessions from colliding. If a program has no end time, RIM assumes it runs for an hour and a half.

**Hosting team.** Which team hosts the live session. The people on that team can see the host code (more on that below). If a program runs itself, like a peer-led group, turn on **No host needed**.

**Recording.** Turn on **Record sessions** and Zoom records the audio to RIM's Zoom account. Everyone in the room sees Zoom's recording indicator. Changing this setting applies to upcoming sessions, including ones already set up.

**Open access (optional).** For a program that welcomes people without a RIM account, turn on open access. It gives you a guest link to share. The link works only while the session is open, and it always leads to that day's room.

## What happens on the day

About **30 minutes before** a session starts, the room opens for hosts. The assigned host and the program's linked teachers see **Enter Zoom as host** on their My Home page. The rest of the hosting team can come in the same way members do, and they get the host code when they do.

About **10 minutes before**, members see **Join on Zoom** on their My Home page.

The first person to come in, host or member, is the moment RIM creates that day's Zoom meeting. Everyone after them joins the same meeting. People type their own name when Zoom opens. Nobody needs a Zoom account.

The room stays open until **30 minutes after** the session ends, so a host can close things down and someone running late can still get in. Members stop seeing the Join button at the scheduled end.

## Who can get in

**Drop-ins and open community groups** are open to any RIM member.

**Classes, events, and retreats that take registration** are for the people registered. A member who isn't registered sees a page saying the session is for registered participants, with a link to the program page. This matches My Home, which only shows them a Join button once they're registered.

**Hosts, the hosting team, and teachers linked to the program** can always get in, registered or not.

**Guests** come through the open-access link, if the program has one.

## The host code

Hosts join under their own name, like everyone else. To take the host controls, they open **Participants** in Zoom, choose **Claim Host**, and type a six-digit code.

RIM shows that code only to people who can host: the assigned host, the rest of the hosting team, the program's linked teachers, and RIM's administrators. Members never see it. Because the whole hosting team sees it, anyone on the team can step in if the assigned host doesn't arrive.

If two people are helping, one claims host and makes the other a co-host inside Zoom.

## RIM's two Zoom rooms

RIM has **two** Zoom rooms. Each one can hold one meeting at a time, so at most two online sessions can run at once.

RIM places each session in a room on its own. People arrive before a session starts and linger after it ends, so when two sessions sit close together, RIM keeps them in different rooms. When every room is in use, it will put back-to-back sessions in the same room rather than turn anyone away. Two sessions that overlap never share a room.

A third session that overlaps two others has nowhere to go. So when you save a program whose schedule would do that, Program Manager tells you, right at the top of the page: **"This overlaps other online sessions on Zoom,"** with the dates and the other programs named. Your change is still saved. It's a heads-up, so you can move one of the sessions before it matters. If RIM regularly needs three at once, talk with Jesse about adding a third room.

## When you change a program

**Change the time or the pattern, and RIM follows.** Any meeting it already made for a future session is removed, and a new one is made at the new time. A session whose room is already open is left alone, so you won't pull the room out from under a host.

**Switch a program to in-person**, and its future Zoom meetings are removed.

**Archive a program**, and it stops opening. Anyone who follows an old link sees that the program has ended.

## What people see when something is off

Every stop on the way into Zoom is a plain page with one clear way forward. If someone tells you they saw one of these, here's what it means.

**"This session isn't open right now."** They came too early or too late. The Join button will be on My Home when it's time.

**"This session is for registered participants."** The program takes registration and they aren't registered. The page links them to the program.

**"This program has ended."** The program is archived.

**"This session can't open right now."** Either both of RIM's Zoom rooms were already in use, or Zoom was briefly unreachable. The page offers **Try again**, and a minute later that usually works. If it keeps happening at the same time each week, two other sessions are probably overlapping it; check the schedules in Program Manager.

## Please don't

- Make Zoom meetings by hand for RIM programs, or share a Zoom link directly. Each session gets its own meeting, so a copied Zoom link works for one day at most. RIM's links always lead to the right room.
- Sign in to RIM's Zoom room accounts, or change their settings, host key, or recordings, without talking with Jesse first.
- Put an end time that's later than the real end "to be safe." It holds a room longer than needed and can block the next session.
