## Sanity / GROQ Rules
- Always exclude drafts: `!(_id in path("drafts.**"))`
- `_type` values are PLURAL (`"programs"` not `"program"`)
- `dayOfWeek` is array ref: `dayOfWeek[]->` not `dayOfWeek->`
- ⚠️ Preview configs: never pass PortableText array as `subtitle` — Sanity expects a string
- Block type `name` values are **permanent** (stored as `_type` in JSON) — `title` is display-only and freely changeable
- Array contains filter: `$slug in field[]->slug.current` (not `field->slug.current ==`)
- Reverse reference (find documents that reference the current document): `*[_type == "programs" && ^._id in linkedCourses[]._ref]` — `^._id` is the outer document's `_id`

## Community Membership Philosophy
RIM is an intentional community. The digital threshold should feel like entering a held, intentional space — not a platform signup. Key principles:
- **Programs are the front door.** No login required to register. Registration form IS the threshold.
- **Real names required.** No anonymous membership. Name collected at registration or on welcome page.
- **One threshold moment.** Community agreements (3-4 lines, checkbox) shown once — either on the registration form (non-logged-in) or on `/account/welcome` (direct login path). Never shown again once `agreedToTerms = true`.
- **Clean member list.** Every User record with `agreedToTerms = true` is an intentional community member. Incomplete accounts (agreedToTerms = false, older than 48h) are deleted by daily cron. Explicit decline deletes account immediately.
- **Google Meet links live on the dashboard only** — not in emails, not on public program pages. Members must be logged in to see them. This protects virtual sessions for members and is good stewardship of dana. Emails (confirmation + reminder) direct members to `/account/dashboard`. Do not change this behavior when updating emails or program pages.
- **Magic link = single flow for join + sign in.** Login page reframed as "Join or sign in." Brief explanation of magic link for new visitors.
