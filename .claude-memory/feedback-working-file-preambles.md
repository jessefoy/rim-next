Re-read the preamble of a working file before editing it. CLEANUP.md, UP_NEXT.md, and FEATURES.md each open with explicit rules for how the file should be maintained. Those rules are easy to drift from when moving quickly.

**Why:** In session 102, a resolved CLEANUP.md item was first marked with strikethrough instead of removed. The preamble is explicit: "Don't leave struck-through residue in the residue file." The drift was caught immediately on re-read and corrected. Jesse named this as exactly the kind of small recovery that keeps the file useful over time.

**How to apply:** Before adding, removing, or reformatting anything in a working document, scroll to the top and read the preamble. This takes ten seconds and prevents the file from accumulating the kind of residue it exists to eliminate. The rule is only as strong as the habit of re-reading it.
