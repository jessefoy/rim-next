# The RIM Guide's file pack

The files a shared Claude project ("RIM Guide", in RIM's Claude for Nonprofits workspace) answers from, so volunteers can ask how the site works and why, and turn what they notice into a clear note for Jesse. Started 2026-10-27.

- `INSTRUCTIONS.md` is pasted into the project's **Set project instructions**. It is not uploaded.
- `1-…` to `7-…` are uploaded to the project's knowledge.
- This README is not uploaded.

**Everything here is visible to every volunteer the project is shared with** ("Can view" members see the instructions and every file). So: no member names except Jesse, no personal contact details, no dana amounts, no keys or IDs, nothing from the session log or UP_NEXT.

**Refreshing:** the project can't sync from GitHub (a shared project can't hold repository content), so the files are uploaded by hand.
- `7-public-page-words.md`: run `node scripts/guide-page-words.mjs volunteer-guide/7-public-page-words.md` (reads the live site).
- `1-` to `6-`: update them when the feature they describe changes. The closing ritual checks this.
- Then, in the project: remove the old copy of each changed file and upload the new one.
